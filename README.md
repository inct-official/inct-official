About INCT

(주)아이앤시티는 디자인과 기술을 연결하여 기업의 아이디어를 실질적인 비즈니스 가치로 구현하는 종합 커뮤니케이션 기업입니다. 웹·앱 및 소프트웨어 개발을 중심으로 UI/UX, 브랜딩, 제품디자인, 미디어, VR·AR·메타버스와 기술 융합 R&D를 수행합니다.
